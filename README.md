## Installation

1. Make a python virtual environment :

2. Active the venv :
**For windows**
```bash
Scripts\Activate.ps1
```
**Linux and MacOS**
```bash
source bin/activate
```

```bash
python -m venv ./
```
3. OpenCV :

```bash 
pip install opencv2-python
```

4. TensorFlow :

```bash
pip install TensorFlow
```
